# 🎮 Pokémon Team Builder

Um projeto desenvolvido para os fãs de Pokémon, com o objetivo de facilitar a criação e organização de equipes Pokémon. A aplicação apresenta uma Pokédex da região de Kanto, permitindo explorar os Pokémon e montar equipes personalizadas.

## ✨ Funcionalidades

- 🔍 **Pokédex:** Explore os Pokémon da região de Kanto.
- 🔎 **Pesquisa:** Encontre Pokémon pelo nome.
- 🎲 **Randomizar equipe:** Gere equipes Pokémon aleatórias.
- 📊 **Análise da equipe:** Analise os Pokémon selecionados.
- 👁️ **Ocultar nomes:** Oculte os nomes dos Pokémon da equipe.
- 🎯 **Filtros:** Utilize filtros para encontrar Pokémon específicos.
- ⚔️ **Movimentos:** Área dedicada aos movimentos dos Pokémon.
- 🏆 **Batalhas:** Área destinada à funcionalidade de batalhas.

## 🖥️ Interface

A aplicação possui uma interface intuitiva, com foco na experiência do usuário e na organização visual dos Pokémon.

## 🚀 Objetivo do projeto

Este projeto foi desenvolvido com o propósito de praticar e aprimorar conhecimentos em desenvolvimento web, lógica de programação, manipulação de dados e criação de interfaces interativas.

## 📌 Melhorias futuras
